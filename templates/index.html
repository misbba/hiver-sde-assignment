Support Pipeline Architecture

The end-to-end customer support automation pipeline consists of 5 modular stages built for high precision and strict safety.

1. Text Normalization

Removes handles, cleans noise, normalizes URLs, and prepares query text.

2. Calibrated Intent Classifier

Predicts intent across 7 categories with calibrated probability distributions (TF-IDF + Calibrated Classifier).

3. Leakage-Filtered RAG Retriever

Retrieves top historical resolution pairs while strictly excluding query text and exact duplicates.

4. Grounded Reply Synthesis

Synthesizes draft response strictly grounded on retrieved AppleSupport resolution steps without hallucination.

About Hiver SDE Assignment

Customer Support Automation & Escalation System built for @AppleSupport inquiries in Kaggle Twitter Customer Support data.

Key Engineering Features
  • Leakage-Filtered RAG Retriever: Excludes query text and exact duplicate tweets to prevent evidence leakage.
  • Calibrated Intent Classifier: 7-category taxonomy tuned specifically for Apple customer inquiry patterns.
  • Conservative Escalation Engine: Explicit human-readable reasons for every AUTO-HANDLE vs ESCALATE decision.
  • Grounded Reply Synthesis: Generates safe, empathetic replies strictly bound to historical resolution steps.
